# Dia 0 original: não tem código

No curso do cipher387, o Dia 0 ("Preparing for work") é só preparação. **Não existe pasta `Day_0`**
no repositório original, então aqui também não há nenhum `.py` do autor.

O que o autor propõe nesse dia, resumido com palavras minhas:

- Ter internet e um computador (ou celular) com **Python** e **Git**, ou então usar um ambiente de
  programação que roda no navegador.
- Ele usava o **Gitpod** em todos os exemplos. O Gitpod deixou de ter plano gratuito para esse uso
  e virou outro produto; o próprio autor avisa no README do repositório que hoje dá para seguir o
  curso pelo **GitHub Codespaces**.
- Para o celular, ele sugere apps que rodam Python (Termux no Android, Pythonista no iOS).
- Ir **um dia por vez**, em ordem. Se aparecer `No module named ...`, é só instalar o pacote com `pip`.
- Ele também sugere marcar o progresso diário num app de anotações. Aqui você pode usar o
  [`DIARIO.md`](../../DIARIO.md) do repositório.

A camada Brasil deste dia (`br/`) transforma essa preparação em código: um verificador de ambiente
e um "mapa" do repositório.
